# App Review notes template

Paste into the version page › **App Review Information › Notes**. Keep it short and concrete.

```
<AppName> works <offline / with an account — demo login below>.

Purchases: <Free core features>. <Pro name> (<plans, e.g. Monthly or Yearly with a 1-week free trial, or Lifetime>) unlocks <what>. Without it, <what happens — e.g. saved data stays readable>.
Where: plans appear <when/where>, and in <Settings path>, which also has Restore Purchases.

Hardware-dependent features: <e.g. The Assistant appears only on devices with Apple Intelligence enabled and runs on-device.>

<Demo account, if sign-in is required: username / password — use a dedicated review account>
```

## Example (RoamReady 1.0)

> RoamReady works offline with no account. Onboarding is free. RoamReady Pro (Monthly or Yearly with a 1-week free trial, or Lifetime) unlocks adding, editing, and the Assistant; without it, saved data stays readable. Plans appear after onboarding and in Profile › RoamReady Pro, which also has Restore Purchases. The Assistant appears only on devices with Apple Intelligence enabled and runs entirely on-device.
